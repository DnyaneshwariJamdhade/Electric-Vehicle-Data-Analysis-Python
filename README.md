# ⚡ Electric Vehicle Population Data Analysis using Python

## 📌 Project Overview

This project analyzes the **Electric Vehicle Population Data** using Python. The main objective is to clean, preprocess, and visualize the dataset to understand electric vehicle adoption trends, manufacturer performance, model year distribution, and regional EV growth.

The project demonstrates the complete Data Analysis workflow, including data cleaning, exploratory data analysis (EDA), data visualization, and business insights.

---

## 🎯 Project Objectives

- Import and explore the Electric Vehicle Population dataset.
- Clean and preprocess the dataset.
- Handle missing values and remove duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful visualizations.
- Extract business insights from the dataset.
- Summarize the findings with a conclusion.

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas

- Matplotlib
- Seaborn

## 📂 Dataset Information

The dataset contains information such as:

- Make
- Model
- Electric Vehicle Type
- Electric Range
- Base MSRP
- Electric Utility

## 📈 Business Insights

- Electric vehicle adoption has increased significantly over recent years.
- Battery Electric Vehicles (BEVs) are more common than Plug-in Hybrid Electric Vehicles (PHEVs).
- A few manufacturers dominate the EV market.
- Electric vehicle registrations are concentrated in specific cities and counties.
- Electric driving range varies across manufacturers and vehicle models.

---

## 🔍 Key Findings

- The cleaned dataset contains more than **51,500** records.
- BEVs account for the majority of electric vehicle registrations.
- Recent model years show rapid growth in EV adoption.
- Electric range differs among manufacturers and vehicle types.
- Regional analysis highlights areas with high EV registrations.

## ✅ Conclusion

This project demonstrates how Python can be used to clean, analyze, and visualize real-world electric vehicle data. The analysis provides meaningful insights into EV adoption trends, manufacturer performance, regional distribution, and electric driving range, helping support data-driven decision-making.
